Perguntas para abrir a carta

Quem recebe responde antes de abrir. É uma brincadeira: depois de 3 erros a carta abre mesmo assim, e as respostas viajam embaralhadas, mas isso não é segurança de verdade.

Guia de presentes

Se você informar o número, ele vai dentro da carta e quem tiver o link consegue vê-lo. Deixe em branco para ela escolher o contato.

Sem o envio, as respostas ficam só na tela de quem recebe.

Enviar

O arquivo funciona sozinho, sem internet. No iPhone, arquivos .html recebidos pelo WhatsApp costumam abrir mal. Para esses casos, use o link.

A carta inteira vai dentro do link. Nada é guardado em nenhum servidor.
